Claude CodeへのMCPサーバー追加、コマンドは claude mcp add の1行で終わります。設定の本体はその後ろの判断2つ。

ひとつはスコープ。プロジェクト必須の接続は.mcp.jsonでコミットして共有、キーは環境変数展開で逃がす。個人の道具はuser、検証中はlocal。

もうひとつは台数です。ツール定義は毎ターンのコンテキストに乗るので、繋ぐほど常時トークンを消費する。「念のため接続」は性能ではなくコストと迷いを足します。

3スコープの使い分けから権限・接続先の選び方まで、設定ガイドにまとめました。

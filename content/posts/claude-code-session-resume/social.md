Claude Codeで中断した作業に戻るのは --continue と --resume の2つで足ります。ただ、戻ってくるのは会話のコンテキストだけ。起動していた開発サーバーも、実行中だったバックグラウンドタスクも、中断中に変わったファイルも戻りません。

なので再開直後の最初の一手は git status からの現状確認。逆に無人の定時実行では、再開を信頼性の仕組みにせず、処理状態を外部キューに持たせて「再入できる」形に寄せています。

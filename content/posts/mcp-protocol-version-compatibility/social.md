「自分はデプロイしてないから壊れてない」が、MCPサーバーでは成り立たない話です。

10-14のClaude Code 2.1.299で、クラウドセッションのMCPコネクタが既定でプロトコル版2026-07-28をネゴシエートするようになりました。その2日後の2.1.302に「新しい版を受けながら応答フィールドを省いたサーバーで、ツールが1本も出ない」不具合の修正。サーバー作者は何もしていないのに壊れて、何もしていないのに直った形です。

合意した版をログに残す、対応しきれていない版は受けない、クライアントのchangelogを監視に入れる。自作MCPサーバー側の点検を記事にまとめました。

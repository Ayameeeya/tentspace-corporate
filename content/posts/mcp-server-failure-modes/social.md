MCPサーバーの運用で効いてくるのは、接続できない朝だけではありません。セッションの途中で構成が変わることです。

ツールが消えたとき、障害なら再試行、設定変更なら再起動。現象は同じ「ツールがない」なのに、正しい対処が逆方向を向いています。Claude Code 2.1.326では管理者設定の途中配布が「部分適用・完全適用は再起動」になり、2.1.328ではサーバー一覧が変わったことがモデルに伝わるようになりました。一覧は揺れるもの、が公式の前提になった形です。

運用側でできる備えは、本処理の前に使うツールの存在を名指しで確かめる工程と、構成変更をセッションの区切りとして扱う判断だと考えています。

失敗モードを「読み込まれない・途中で変わる・黙って外れる」の3つに分けて記事にまとめました。

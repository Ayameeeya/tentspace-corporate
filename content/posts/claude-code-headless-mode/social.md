Claude Code、-p を付けるだけで対話UIなしのCLIコマンドになります。パイプで繋げて、CIやcronから呼べる。

ただしヘッドレスの本題はコマンドではなく設計です。対話モードでは権限確認に人間が答えますが、無人実行では答える人がいない。だから「その場で聞かれて答える」が「先に列挙して渡す」に反転します。

--allowedTools で最小許可、--max-turns とタイムアウトで実行量に上限、--output-format json でエラーとコストを機械判定。書き込みを渡すのは、テストやlintなど機械的な合格条件が書けるジョブだけ。

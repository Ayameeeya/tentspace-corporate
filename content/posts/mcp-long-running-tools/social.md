数十秒かかる処理をMCPツールにするとき、タイムアウトを何秒にするかから考え始めると詰まります。決めるのは秒数ではなく「誰がどこで待つか」でした。

選択肢は3つ。呼び出しの中で待ち切る、受付と完了を分けてあとから取りに行く、クライアントに待ちを肩代わりさせる。3つ目はClaude Code 2.1.319で入った新顔で、タスクとして走ったツール呼び出しを即バックグラウンド化して、完了時に結果をモデルへ渡します。環境変数で待機側にも固定できます。

自分の無人運用では、まだ待機側に固定しています。結果が「あとから届く」仕組みは、届かなかったことが見えにくい。取り逃しを数える監査を先に作ってから解放する順番にしました。

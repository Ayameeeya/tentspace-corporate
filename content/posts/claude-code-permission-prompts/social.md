Claude Code 2.1.319の新設定、無人運用の人は一度立ち止まって読む価値があります。

permissions.denyInsteadOfPrompting。許可プロンプトで待つはずのツール呼び出しを拒否して、ターンをそのまま続行する設定です。無人実行では「確認」が「停止」と同義だったので、止まらない選択肢が公式に増えた形。

ただ、同時期の修正履歴を並べると見え方が変わります。止まったターンがfailedに記録されない不具合、拒否されたのに終了コード0を返す不具合。安全側の動作は入っていたのに、外からは成功に見えていた。

止めるか、拒否して進むか、の前に「止まった・拒否されたを数えられるか」。そこから整理した1本です。

# 記事執筆ガイド

> 憲法層。本ガイドは、人間・AI を問わずすべての書き手が参照する記事記法の正本です。

## 利用可能な MDX コンポーネント

記事側で import は不要です。以下のコンポーネントは、すべての記事へグローバルに提供されます。

### LinkCard

一次情報や関連する記事を、タイトル・説明・画像・リンク先ドメイン付きの横長カードで示します。

内部記事は `slug` で指定します。タイトル、説明、カバー画像はコンテンツコレクションからビルド時に解決されます。存在しない slug や下書き記事を指定すると検証に失敗します。

```mdx
<LinkCard slug="claude-code-custom-skills-guide" />
```

外部ページは完全な `https://` URL を指定します。OGP と favicon はビルド時に取得され、キャッシュされます。取得できない場合は通常のテキストリンクとして表示され、記事のビルドは継続します。

```mdx
<LinkCard url="https://blog.cloudflare.com/example/" />
```

`slug` と `url` はどちらか一方だけを、文字列として指定してください。

## LinkCard の使い所

- 一次情報の主要リンクと、読者の次の理解につながる内部記事は、本文中のベタ貼りより LinkCard を推奨します。
- 目安は 1 記事につき 1〜4 枚です。
- 本文中の軽い言及や、文章の流れの中で読む短い参照はテキストリンクのままで構いません。
- カードだけを連続して羅列せず、それぞれのリンクを置く理由が分かる本文を添えます。

## 運用ルール

本ガイドは、人間・AI を問わず全書き手の正本です。**MDX コンポーネントを追加したら、必ず本ガイドに記法と使い所を追記します。** このリポジトリを読むエージェントは、個別のプロンプトへ記法を書き写さず、本ガイドを参照してください。

既存記事への遡及適用は不要です。リライトや情報更新の機会に、自然な範囲で LinkCard へ置き換えます。
